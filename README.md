# Earthquake Viewer

Interactive earthquake viewer using live USGS earthquake data. The map opens
centered on the Pacific Northwest; earthquake results follow the current map
bounds worldwide.

- M2.5+ earthquakes from the previous 7 days
- 10 most recent earthquakes in the table, expandable to 100
- All matching earthquakes are shown on the map, up to a safety cap of 5,000
  events per map view. If more results match, the map and table show the
  newest 5,000 and the status message reports that the result set was capped.
- Volcano and fault overlays
